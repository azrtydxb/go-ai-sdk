# go-ai-sdk v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.1 of an idiomatic Go port of the Vercel AI SDK: `GenerateText`/`StreamText` with multi-step tool calling, `GenerateObject[T]`/`StreamObject[T]`, `Embed`/`EmbedMany`, over a provider spec implemented by OpenAI, Anthropic, and Google (Gemini).

**Architecture:** Three layers in one Go module: `provider` (interfaces + unified types, no logic), `ai` (all orchestration: tool loop, retries, object decoding, batching), `providers/*` (wire-format translation only). Shared plumbing in `internal/` (SSE, JSON Schema reflection, retry, partial JSON). Spec: `docs/superpowers/specs/2026-08-02-go-ai-sdk-design.md`.

**Tech Stack:** Go 1.26, stdlib only (no external dependencies in v0.1). `iter.Seq` for streams, generics for tools/objects, `httptest` for all provider tests.

## Global Constraints

- Module path: `github.com/azrtydxb/go-ai-sdk`; `go.mod` declares `go 1.26`.
- Zero external dependencies (stdlib only) in v0.1.
- Providers NEVER retry, loop tools, or parse objects — that logic lives once in `ai`/`internal`.
- All exported errors matched via `errors.As`/`errors.Is`; context cancellation must propagate everywhere.
- Every task: `go vet ./...` and `go test ./...` must pass before commit.
- Commit messages: conventional (`feat:`, `test:`, `chore:`), each ending with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- API keys default to env vars: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_GENERATIVE_AI_API_KEY`.

```go
type APICallError struct {

    URL          string
    ResponseBody string

}
func (e *APICallError) Error() string // "ai: API call to <URL> failed: status <code>: <Message>"

func NewAPICallError(statusCode int, url, body, message string) *APICallError
// sets Retryable = statusCode == 429 || statusCode == 408 || statusCode >= 500

type NoObjectGeneratedError struct {
    RawText string
    Cause   error
}
func (e *NoObjectGeneratedError) Error() string
func (e *NoObjectGeneratedError) Unwrap() error

type NoSuchToolError struct{ ToolName string }
type InvalidToolArgumentsError struct {
    ToolName string
    Args     json.RawMessage
    Cause    error
}
func (e *InvalidToolArgumentsError) Unwrap() error
type ToolExecutionError struct {
    ToolName string
    Cause    error
}
func (e *ToolExecutionError) Unwrap() error

type RetryError struct {
    Attempts int
    LastErr  error
}
func (e *RetryError) Unwrap() error // LastErr

// internal/retry/retry.go
// Do calls fn up to 1+maxRetries times. Retries only when IsRetryable(err).
// Backoff: base 500ms, doubling, full jitter (rand.N over the window), cap 8s.
// Honors ctx: returns ctx.Err() if canceled while waiting.
// After exhaustion returns the last error unchanged if maxRetries==0,
// else &ai.RetryError{...}. To avoid an import cycle, retry declares:
type Retryable interface{ IsRetryable() bool }
func Do[T any](ctx context.Context, maxRetries int, fn func() (T, error)) (T, error)
```

`*ai.APICallError` gets method `func (e *APICallError) IsRetryable() bool { return e.Retryable }` so `retry` detects it without importing `ai`. `retry.Do` wraps exhausted retries in its own `*retry.ExhaustedError{Attempts int; LastErr error}`; `ai` converts that to `*ai.RetryError` at its call sites (Task 6).

### Task 4: `internal/schema` — JSON Schema from Go structs

**Files:**

- Produces:

```go
// For reflects T (must be a struct) into a JSON Schema object:
// {"type":"object","properties":{...},"required":[...],"additionalProperties":false}
// Rules:
// - field name: `json` tag name, else Go name; json:"-" skipped
// - required: all fields EXCEPT pointer types and those with omitempty/omitzero
// - types: string→"string"; bool→"boolean"; ints/uints→"integer";
//   floats→"number"; slice/array→"array"+items; map[string]X→"object"+
//   additionalProperties; nested struct→recursive object; *T→schema of T;
//   json.RawMessage→{} (any)
// - `jsonschema` tag, comma-separated: description=...,enum=a|b|c
//   (enum values coerced to the field's type; description commas may be
//   escaped as \,)
// - cycles: return error (no $ref support in v0.1)
func For[T any]() (json.RawMessage, error)
func ForType(t reflect.Type) (json.RawMessage, error)
```
